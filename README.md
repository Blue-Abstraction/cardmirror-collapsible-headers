# CardMirror Collapsible Headers Plugin
Collapsible Headers is a plugin by Evan Xiang for Anthony Truf's [CardMirror](https://github.com/ant981228/cardmirror).

Collapsible Headers allows debaters to collapse and expand Pocket, Hat, and Block styles to make viewing documents quick and efficient.

Email me at `blueabstractionoop@gmail.com` for any comments, issues, or more features you want to see added!

## Installation
1. Open CardMirror and open `Settings` (the gear icon on the top right).
1. Navigate to `Plugins`.
1. Copy the link of this repository and paste it into `INSTALL A PLUGIN`.
1. Press `Install` and `OK`.

## Current Features
- Clicking the dropdowns to the left of Pocket, Hat, and Block styles collapse its contents and can be pressed again to expand.
- Commands to collapse/expand certain headers or the entire document, as well as a command to focus the current selection by collapsing everything else are available in CardMirror's Smart Search feature.
- Customizable dropdown in `Settings`: different colors and sizes!
