# CardMirror Collapsible Headers Plugin
Collapsible Headers is a plugin for [CardMirror](https://github.com/ant981228/cardmirror) by Anthony Truf.

It's pretty self-explanatory: Collapsible Headers allows debaters to collapse and expand Pocket, Hat, and Block styles to make viewing documents quick and efficient.

## Current Features
- Clicking the dropdowns to the left of Pocket, Hat, and Block styles collapse its contents. Press again to expand.
- "Collapse All" and "Expand All" commands are available in CardMirror's Search feature
